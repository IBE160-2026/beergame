- `landing-<bredde>.png`: Landing. Ved 200 % tekst står overskriften over hele bredden med ingressen under (før: ett ord per linje). Ved 1280 og 390 px uendret. Samsvarer.
- `oversikt-<bredde>.png`: Oversikt med Varselbånd. Sidehodet holder seg på én linje ved 390 px (navnet brytes i sin egen boks, «Logg ut» krymper ikke); «under 1 min» brytes ikke lenger fra hverandre. Samsvarer.
- `spillinnsikt-<bredde>.png`: Spillinnsikt. «Lager og restordre» har direkte etiketter (hver rolles største lager over stolpen, største restordre under). Rulleregionene viser en 1 px `axis`-strek og et synlig tynt rullefelt i stedet for fading mot `paper` (DESIGN.md: ingen fades eller gradienter). Samsvarer.
