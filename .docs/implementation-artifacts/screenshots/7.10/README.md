# Story 7.10: visuell kontroll (uavhengig, ingen menneske i loopen)

Fersk Klasse med to Studenter, fire Meldinger (til alle, til Spill, til én Student, én lang med ubrytelig ord). Alle bilder 390 px, 1280 px og 1280 px med 200 % tekst; ingen sidelengs scroll målt i noen av dem. Ingen kodeendringer var nødvendig.

- `student-uten-meldinger-<bredde>.png`: Hjem uten Meldinger. Ingen «Meldinger»-seksjon. Samsvarer.
- `student-meldinger-<bredde>.png`: Hjem med fire Meldinger etter Stegene/Neste frist, nyeste først: avsender, Oslo-tid, full tekst, linjeskift bevart, lang tekst og ubrytelig ord brytes. Ingen Klassenavn (én Klasse). Ingen knapper. Samsvarer.
- `staff-tom-<bredde>.png`: «Meldinger» uten sendte Meldinger: tom-linje og «Skriv melding til alle». Samsvarer.
- `staff-meldinger-<bredde>.png`: stab-listen med mottaker (overskrift), avsender, tid, antall studenter, tekst og «Skriv ny melding». Ingen primærknapp, kun lenker. Samsvarer med Meldinger-kortet i 09-alle-sider (mottaker + tekst), uten Send-knapp siden dette er lesevisning.
- `staff-oversikt-header-<bredde>.png`: Oversikt med lenken «Meldinger» ved siden av «Skriv melding til alle». Samsvarer.

Ikke dekket: Student i to Klasser (Klassenavn per Melding) er ikke tatt som skjermbilde (dyrt å seede); ikke verifisert visuelt og ikke funnet dekket av egen test.
