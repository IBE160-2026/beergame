## C. Latency

18. Artificial Analysis page for "Claude Haiku 5.5 (Max)": output speed 234.4 tokens/s (Anthropic API; tier median 112.7); TTFT shown as 348.07 s vs tier median 1.73 s. The page's FAQ gives release date 2026-10-07. The 348 s TTFT is almost certainly "Max" reasoning-effort mode (time-to-first-answer-token after thinking) or a data error; do not use for planning. No Gemini Flash-Lite / GPT-small comparison retrieved. | https://artificialanalysis.ai/models/claude-haiku-5-5 | Artificial Analysis (independent benchmark) | page dated Oct 2026 (undated otherwise) | 2026-10-26 | low for TTFT (anomalous), medium for 234 t/s | performance-number
   Contradiction to flag: 234 t/s output speed vs 348 s TTFT on the same page are only compatible if reasoning/thinking tokens are hidden before first token. A game agent should call with low/no thinking; need a non-"Max" variant row.
19. Back-of-envelope (my calculation, not sourced): if an order response is ~100-200 output tokens at ~234 t/s, generation is ~1 s; the dominant term is TTFT, which was not reliably retrieved. 3 AI roles can be called in parallel (they decide simultaneously in the standard game), so wall-clock per turn ~= one call, not three.
