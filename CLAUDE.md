# Prosjektinstruksjoner

**Logg sesjonen.** Når en oppgave/økt avsluttes, før sluttoppsummeringen, bruk `sesjonslogg`-skillen: dokumenter Oppgave + Plan + Resultat + åpne punkter per bruker i `.logs/<bruker>/`, og før åpne punkter som GitHub Issues i dette repoet med `gh issue` (etikett `agent`), aldri i `issues.md`. Les åpne punkter med `gh issue list --label agent --state open` før du logger, lukk løste med `gh issue close`, og oppgi `Issue #N` i Åpne punkter i loggfila. Issuene er offentlige: ingen hemmeligheter eller informasjon om andre prosjekter.
